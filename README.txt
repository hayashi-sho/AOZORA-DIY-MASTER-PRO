AOZORA. DIY MASTER PRO v20.0 アイコン統合版

【GitHubへの登録】
ZIPを解凍し、このフォルダにある index.html / manifest.webmanifest / PNG画像5個をすべてリポジトリの一番上（ルート）にアップロードしてください。フォルダだけアップすると表示されないことがあります。

【表示される場所】
・favicon-32.png / favicon-48.png : ブラウザタブ等
・apple-touch-icon.png : iPhone「ホーム画面に追加」用
・icon-192.png / icon-512.png : アプリ用アイコン / Web App Manifest
・アプリ左メニューにもアイコンを表示

【iPhoneでアイコンを表示】
SafariでGitHub Pagesの公開URLを開き、共有 > ホーム画面に追加。
すでにホーム画面に追加済みなら古いアイコンがキャッシュされることがあるため、追加し直してください。

【注意】
・インターネットアクセスなしでも開ける「オフライン保証」はしていません（Service Worker未導入）。
・旧バージョンのブラウザー保存データは更新前にアプリからJSONバックアップを作成してください。
・設計図や接合部の図は参考用です。強度・下穴径・安全性を保証しません。
・このパッケージはGitHub Pagesで使用できる静的ファイル一式で、GitHubへ自動アップロードするものではありません。
